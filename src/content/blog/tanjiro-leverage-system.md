## 01 心法：為什麼一定要借錢

我們活在**赤字經濟**裡。現代貨幣是由債務創造出來的，沒有債務就沒有貨幣，沒有貨幣就沒有資產價格的推升。美債 40 兆、41 兆、42 兆會一直堆上去，這不是危機，是這個體系的本質。

> That is what our money system is. If there were no debts in our money system, there wouldn't be any money.
>
> 1941 年有人拿政府債務問題問聯準會總裁，他這樣回答。

所以債務只能靠兩件事解決：用 AI、機器人、高速運算讓經濟成長得更快，或者用通膨慢慢稀釋。不管是哪一種，**握有貨幣的人吃虧，握有優質資產的人受益**。

### 實質負利率：連利息都是通膨幫你付的

主計總處公布的 CPI 年增率是 2.73%，PPI 是 18.12%。當借貸成本低於物價上漲和資產增值速度，就是實質負利率。這時候：

- 借未來注定貶值的貨幣，搶今天便宜的稀缺資源。
- 跟上 CPI 只是讓你活下去，**超越 global M2 成長**才能讓你活得滋潤。
- 0050、2330 一年漲 70%，你的薪水一年漲幾 %？這就是 **r > g**。

> 資產端每年 8–12% 複利，負債端一年 2–3% 複利。我花一年的時間借出三輩子的薪水搶資產，再用祖孫三輩子的時間慢慢還。更正，是能借就繼續借。

## 02 佛畏系統：把財務自由當成系統問題

萬維鋼的《佛畏系統》可以對應三種面對財富的層次：

| 層次 | 說明 |
|------|------|
| 凡夫畏果 | 只看結果。被房貸、生活費追著跑，痛苦了才後悔，只能繼續拿時間和體力換錢。 |
| 菩薩畏因 | 看到因果。發現靠體力賺錢會邊際遞減，開始控制欲望、追求工作與生活平衡。 |
| 佛畏系統 | 看清赤字經濟的底層邏輯，**直接改變系統結構**，建立自己的應對框架。 |

「靠薪水和勞力撐負債」本身就是極度脆弱的系統，你一停下勞動，系統就崩潰。最高層次是建立<strong>「資產自己養負債」</strong>的正向循環：讓資產產生的收益去付利息和生活開銷，而不是拿時間和健康硬撐。

> 市值型、配息型、主動型、正二都好，負債一定是靠資產撐的，不可能靠薪水撐。

工具只是道路，**總資產 N 才是終點**。不要跟別派投資人爭誰比較對，你的 N 持續變大才是重點。

## 03 系統結構：水之呼吸與日之呼吸

還沒算股票股息。也就是說，**現金池的利息付掉負債的利息，股票池純粹拿來增值**。

### 為什麼防禦池放現金，不放債券？

- 現金就是沒有 duration 的債券；債券只是有利息的貨幣。
- 這五年很清楚沒有什麼股債反向，崩盤時債只會一起跌爛。
- 崩盤時你真正需要的是 **liquidity**，才能在別人拋售時好整以暇吃血饅頭。
- 不要再什麼股債平衡了。

## 04 壓力測試：漲、還款、腰斬

| 情境 | 做法 | 結果 |
|------|------|------|
| 一、股票 +8% | 只增值，不賣出 | 總資產 5 億 → 5.2665 億，負債不變。LTV 40% → **37.98%** |
| 二、股票 +8% | 實現獲利 2,600 萬加利差 65 萬，全部還本金 | 負債 2 億 → 1.7335 億。LTV 40% → **34.67%** |
| 三、股票腰斬 −50% | 不賣、不還 | 股票 3.25 億 → 1.625 億，總資產 3.375 億。LTV 40% → **59.3%** |

情境一說明**時間本身就會幫你降槓桿**：就算不額外還款，資產分母變大，槓桿比率自然下降。

情境三是最壞的狀況。這時候還有本業收入可以補擔保，而且 1.75 億的現金池還在，可以去撿便宜。

> 但請注意，這只是資產負債比的壓力測試，不代表所有券商都不會追繳。實際結果仍取決於擔保品折扣率、維持率規則及匯率而定。

## 05 錢從哪裡借

### A. 股票質押與 Lombard loan（我主要用這個）

如果連匯率風險都不想承擔，最簡單的版本：用 **3,000 萬**台幣買 0050 和台積電，設質借出 **50%（1,500 萬）**，再買進、再設質。總擔保品 4,500 萬除以總借款 1,500 萬，維持率 **300%**，要整包大跌 **56%** 才需要補錢。

銀行為什麼不推薦這種做法？當然呀，賣債手收才高呀。

網友分享的星展銀行條件可以參考：台股質押需要在銀行放 3,000 萬 AUM；進件、審核、對保、建額度、撥款大約 2–3 週。Trust lending 維持率跌破 175% 會收到簡訊，五個營業日內要補到 180%。現在很多銀行會主動找你開 PB（私人銀行帳戶），用 Lombard loan 借錢。

### B. 信貸：重額度，不重利率

| 方案 | 額度 | 條件 | 月付 |
|------|------|------|------|
| 只繳息 | 1,000 萬 | 4%，不還本 | 約 3.3 萬 |
| 本息攤還 | 350 萬 | 3%，120 期 | 約 3.3 萬 |

同樣月付，我選前者。額度的差距比 1–2% 的利率差重要得多，能放進資產的錢差了快三倍。

**搬家滾貸款**：信貸綁約滿一年後，在到期前 1–2 個月找第二家銀行轉貸代償。轉貸代償不受 DBR 22 倍限制，一家額度借滿再找下一家。

### C. 注意：2026 年的政策變化

政府把質押封死了。本來**不限用途**的好處是，需要錢的時候不必賣資產，可以從 0050、台積電壓出錢來。現在改成限用途，利率也從 1.8% 升到 3% 以上，我借一個億一年要多付 100 萬利息。

我的做法是**更節制消費來補這 100 萬**，而不是賣 0050。要賣也先賣車賣錶，因為 0050 賣了之後要用更高的價格才買得回來。

更細膩的操作會用到 OBU、外保內貸，這是進階版課程，這裡不展開。

## 06 買什麼、不買什麼

**買**

- 0050、台積電（2330）
- QQQ、VT、VOO 等全市場或大盤指數
- 有創造力、生產力、能改變人類歷史的壟斷性科技巨頭
- 資產家在買的東西，例如寶佳在持有的馬家金（元大金）
- 防禦池：美元現金、MMF、T-Bill

**不買**

- 長天期美債（30 年、1.875% 那種）
- 債券質押：本質是在玩匯，賺利息往往賠匯差
- 股債平衡
- 只會越來越多、購買力越來越差的「廢紙」
- 無法創造資產的消費

> 2021 年台積電 400，2026 年台積電 2,500。你滿手美元美債，到了 2026 年只能買六分之一的 2021 年台積電股權。誰比較有價值？

**關於美元短債**：如果你有美元收入、美元負債或美元支出，像波克夏一樣持有 T-Bill 非常合理。但如果你的資產負債表是台幣本位，台幣從 31 升到 30 就吃掉一整年利息。台幣換美元本質上是「放空台幣、做多美元」，一定要把 FX risk 算進去。

**人多的地方不要去，這句話只說對了一半**：韭菜多的地方不要去，資產家多的地方要緊緊跟隨。

## 07 操作紀律

1. **一張不賣，死磕到底。** 我沒有主動投資或量化交易的慧根，跟孔明比智商我打不過，但我可以跟他比耐心。
2. **不看盤，一年進出不到 10 次。** 其他時間專心工作、閱讀、運動。我的 cortisol 從來不波動，這樣活得比較久。
3. **一段時間壓出來，繼續買。** 資產漲了、擔保品變多，就再借出來買更多。所有資產都是跟銀行借來買的。
4. **崩盤時用現金撿。** 水之呼吸的現金就是為這一刻準備的。別人吃暫停卡借不到錢時，你要擴大跟別人的資產差距。
5. **利率上升時，降級消費，不賣股票。** 先砍無效消費，再賣車賣錶，最後才輪到資產。

> 格鬥場上有一句話：在絕對的體重差異面前，所有的格鬥技巧都是浮雲。

資金也是一樣。面對絕頂聰明的人，我只能用絕對愚蠢的方式：先借出三輩子的薪水投入今天的指數，讓通膨帶我飛。

## 08 生活心法：不受誘惑

> 猗窩座のいうように、肉体が滅びることのないことが強さなのではなく、人間にとっての強さとは、誘惑に負けることなく、正しい振る舞いを貫けるということです。
>
> 小川仁志《「鬼滅の刃」で哲学する》

- **節制消費是定力**：精緻窮、即時滿足就是現代人體內的「鬼之血」。
- **放空貨幣是膽識**：通膨巨浪下，法幣就是不斷貶值的負債。
- **買進資產是執行力**：把省下來的錢持續換成優質股權，過程枯燥，時間會回報你。

投資觀念越好的人，越不會花大錢在吃喝玩樂上，因為沒辦法創造資產的消費全部都是**無效消費**。面對升息循環只有九個字：**高築牆**（累積資產）、**廣積糧**（創造現金流）、**緩稱王**（杜絕一切無效消費）。

## 09 終局：資產永不賣，債務永不還

有人問我：「會規劃 deleverage 的一天嗎？還是 borrow until dead？」

如果資產和債務都在個人名下，總有一天要 deleverage，因為人遲早會 expire，遞延的資本利得稅也會變成遺產稅。資產到了一定部位，你就會思考用 **DBU 和 OBU** 的架構，**換子孫當股東**就好。

> 資產永不賣，債務永不還。借錢要還？那誰還借！

## 10 2026 年的局勢判斷

- **升息循環**：11 月選完，12 月如果美國升息，台灣很難不跟。就算央行不升，銀行也會自己提高利率，消費性貸款和房貸會全面站上 3%。
- **i 型經濟**：不是 K 型，是 i 型。上面那一小點不怕高利率、借得到錢繼續擴張，其他人吃暫停卡。
- **株高不況**：台灣會比日本更嚴重。股市可能繼續創高，但餐飲、零售、服務業會在通膨、租金、缺工、基本工資四殺下死一片。
- **匯率**：台幣站上 32，台積電受惠 AI 已經賺爛。要學日本的智慧，在日正當中把外匯換成美元收益。
- **下一個稀缺資產是「資本」**：四大科技巨頭年資本支出衝向 9,500 億美元，借不到錢的企業和個人，會在高利率時代被淘汰。
- **兩條路**：在台灣的存量市場卷成蠱王，或者走出去打增量市場的世界盃。

## 12 整理者的檢查清單（不是他的觀點）

上面是他的方法。照做之前，先確認這些他的條件你有沒有：

- **本業收入。** 他是在日本執業的醫師。情境三那句「我們還有收入可以補擔保」，是整套系統最後一道防線。收入不穩的人沒有這道防線。
- **資產規模與管道。** 他的範例是 5 億和 3,000 萬，PB、Lombard loan、OBU、外保內貸都需要高資產門檻。一般人能拿到的通常是信貸，利率更高，還要靠薪水還本息，跟「資產養負債」是兩回事。
- **續借風險。** 「債務永不還」的前提是銀行一直願意借。他自己的貼文就記錄了 2026 年政策收緊（質押限用途），利率從 1.8% 升到 3% 以上。利率再升或銀行收緊，到期就得還本。
- **利差很薄。** 5 億範例的正利差是 3.8% 減 3% 換算出來的 65 萬，只占負債的約 0.33%。借款利率再升約 0.33%，或現金收益降約 0.37%，利差就歸零。
- **匯率。** 他提醒台幣本位的人買美元短債有 FX risk，但他的防禦池自己就放美元現金和 T-Bill。他的收入和生活在日本，幣別結構跟你不同。
- **樣本期間。** 這些貼文寫在台積電、0050 大漲之後。這套方法還沒經歷過長期下跌或多年盤整，貼文裡也看不到他的對帳單、虧損或被拒貸的紀錄。

**可以先學的低風險部分**：節制消費、長期持有全市場指數、少交易、保留夠撐過下跌的現金。**要借錢之前**：先用上面的試算器跑一次股票 −50% 加上半年沒收入的情境，撐得住再說。

<script>
  (() => {
    const $ = (id) => document.getElementById('tj-' + id);
    const presets = {
      big: { e: 30000, d: 20000, c: 35, rc: 3.8, rd: 3, x: 50 },
      pledge: { e: 3000, d: 1500, c: 0, rc: 3.8, rd: 3, x: 56 },
      small: { e: 300, d: 100, c: 20, rc: 1.5, rd: 3.5, x: 40 },
    };
    const fmt = (v) => (Math.abs(v) >= 10000 ? (v / 10000).toFixed(2) + ' 億' : Math.round(v).toLocaleString() + ' 萬');
    const pct = (v) => (v * 100).toFixed(1) + '%';
    const num = (k) => +$(k).value || 0;
    function calc() {
      const e = num('e'), d = num('d'), c = num('c') / 100, rc = num('rc') / 100, rd = num('rd') / 100, x = num('x') / 100;
      const A = e + d, cash = A * c, stock = A * (1 - c);
      const interest = d * rd, cashInc = cash * rc, spread = cashInc - interest;
      const A2 = cash + stock * (1 - x);
      const ltv = A > 0 ? d / A : 0, ltv2 = A2 > 0 ? d / A2 : Infinity, cover = d > 0 ? A2 / d : Infinity;
      $('o1').textContent = pct(ltv);
      $('o2').textContent = fmt(interest) + ' / ' + fmt(cashInc);
      $('o3').textContent = (spread >= 0 ? '+' : '') + fmt(spread);
      $('o3').className = spread >= 0 ? 'good' : 'bad';
      $('o4').textContent = fmt(A2);
      $('o5').textContent = isFinite(ltv2) ? pct(ltv2) : '-';
      $('o5').className = ltv2 < 0.5 ? 'good' : ltv2 < 0.7 ? 'mid' : 'bad';
      $('o6').textContent = isFinite(cover) ? (cover * 100).toFixed(0) + '%' : '-';
      $('o6').className = cover >= 1.75 ? 'good' : cover >= 1.3 ? 'mid' : 'bad';
      const n = [];
      if (spread < 0) n.push('現金池的收益付不起利息，差額每年 ' + fmt(-spread) + ' 要靠薪水補，這就不是「資產養負債」了。');
      if (cover < 1.3) n.push('下跌後資產 / 負債低於 130%，在台股質借常見的追繳線附近，可能要補錢或被斷頭。');
      else if (cover < 1.75) n.push('下跌後資產 / 負債低於 175%，碰到網友分享的 trust lending 通知線。');
      if (!n.length) n.push('這組數字在這個跌幅下還在安全範圍。試試把借款利率加 1%，或把跌幅改成 60%。');
      n.push('試算用總資產 / 負債近似維持率，實際以銀行的擔保品折扣率與規則為準。');
      $('note').textContent = n.join(' ');
    }
    document.querySelectorAll('.tj-inputs input').forEach((i) => i.addEventListener('input', calc));
    document.querySelectorAll('.tj-btns button').forEach((b) =>
      b.addEventListener('click', () => {
        const p = presets[b.dataset.p];
        for (const k in p) $(k).value = p[k];
        calc();
      })
    );
    calc();
  })();
</script>
